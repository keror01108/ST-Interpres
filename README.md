# Interpres — 이야기 통역사

롤플레잉에 특화된 SillyTavern용 LLM 번역 확장입니다. **v1.3.0**

기계번역(구글·DeepL)의 어색한 문어체 대신, LLM이 캐릭터의 말투와 장면의 온도까지 살려 번역합니다.
원문은 그대로 모델에게 전달되고 화면에만 번역이 표시되므로, 번역이 스토리 품질에 영향을 주지 않습니다.

## 주요 기능

| 기능 | 설명 |
|---|---|
| 응답 자동 번역 | AI 응답이 끝나면 화면에만 번역 표시 (원문은 모델 컨텍스트에 유지) |
| 입력 자동 번역 | 한국어로 쓰면 모델에겐 영어로 전달, 화면엔 내 원문 유지 |
| 말투 카드 | 캐릭터별 존댓말/반말·어미·말버릇을 기록해 번역 문체를 고정. LLM 자동 스캔 지원 |
| 용어집 | 이름·지명·기술명 표기 고정. 캐릭터 카드에서 자동 수집 |
| 번역 결 다이얼 | 직역 위주 ↔ 과감한 의역, 5단계 |
| 번역 기억(캐시) | 문단 단위로 번역을 기억 — 메시지 수정 시 바뀐 문단만 재번역해 비용 절감 |
| 봉인(형식 보호) | 코드·{{매크로}}·이미지·URL·지정 HTML 태그를 `<seal-N/>` 마커로 보호하고 번역 후 복원. 유실 시 자동 재시도 |
| 문맥 연속성 | 직전 원문·번역 쌍을 참고로 첨부해 호칭·대명사·어조 유지 |
| 대조·편집 | 메시지별 원문·번역 나란히 보기 + 번역 직접 수정 |
| 독자 지시문 | "대사는 반말로, 나레이션은 문어체로" 같은 상시 요구사항 |
| 프롬프트 편집 | 고급 탭에서 번역 시스템 프롬프트를 직접 수정. `{{source_lang}}` `{{target_lang}}` `{{pair_notes}}` 매크로는 방향에 따라 자동 치환 |
| 비차단 | 번역은 메인 생성 파이프라인을 점유하지 않아 번역 중에도 채팅 가능 |
| 모델 연결 3종 | 현재 API / 커넥션 프로필 / 커스텀 OpenAI 호환 API 직접 입력 |
| 프리필 | 번역가의 첫 마디를 미리 채워 안전 필터의 빈 응답을 뚫습니다 |

## 설치

`SillyTavern/data/<user>/extensions/` 또는 `public/scripts/extensions/third-party/` 아래에
이 폴더를 통째로 복사한 뒤 SillyTavern을 새로고침하세요.

## 사용법

1. 확장 설정 → **Interpres — 이야기 통역사** 드로어를 엽니다.
2. **기본** 탭에서 감상어(화면 언어)와 모델어를 고르고 자동 번역을 켭니다.
3. **모델** 탭에서 번역에 쓸 모델을 연결합니다. 저렴한 소형 모델을 커스텀 API로 붙이는 걸 추천합니다.
4. (선택) **용어·말투** 탭에서 "자동 수집"과 "말투 스캔"을 눌러 카드 기반 프로필을 만듭니다.

### 메시지 버튼

- 🌏 : 이 메시지 번역 / 원문으로 되돌리기 (토글)
- 🔄 : 재번역 — 캐시를 무시하고 처음부터 다시 번역
- ⚖️ : 원문·번역 대조 및 번역 직접 수정

### 슬래시 명령

- `/interp on|off` — 확장 켜기/끄기
- `/interp-msg 12` — 특정 메시지 번역 (번호 생략 시 마지막 AI 응답)
- `/interp-chat` — 아직 번역 안 된 응답 일괄 번역
- `/interp-book` — 지금 이 챗방의 용어집·말투 카드가 실제로 무엇인지 그대로 출력 (다른 챗방 항목이 섞였는지 확인용)

## 설정 항목

| 항목 | 기본값 | 설명 |
|---|---|---|
| 감상어 / 모델어 | ko / en | 표시 언어와 모델 언어 |
| 번역 결 | 균형(3) | 1 직역 위주 ~ 5 과감한 의역 |
| 문맥 쌍 수 | 2 | 직전 원문·번역 쌍 첨부 개수 (0–6) |
| 번역 기억 | 켬 | 문단 단위 캐시 |
| {{매크로}} 봉인 | 켬 | 매크로 구문 보호 |
| 형식 검증 재시도 | 켬 | 봉인 유실 시 1회 재시도 |
| 번역 제외 태그 | (없음) | 상태창 등 통째로 보호할 태그명 |
| 응답 토큰 한도 | 8192 | 번역 호출 max_tokens |
| 프리필 | (없음) | 번역가의 첫 마디를 미리 채움. 비워두면 사용 안 함 |

## 변경 이력

### v1.3.0
- **프리필 추가** ([모델] 탭): 안전 필터가 본문을 비워 돌려보내 `빈 응답` 오류가 나는 모델을 위해, 번역가의 첫 마디를 미리 채워 그 뒤를 이어 쓰게 합니다. 프리필 문장 자체는 번역 결과에 포함되지 않으며, 용어·말투 자동 수집과 연결 테스트에는 적용되지 않습니다 (JSON 응답이 깨지므로)
- **"빈 응답" 오류 메시지 개선**: `finish_reason`을 함께 보여주고, 필터가 의심되면 프리필을 안내합니다
- **지구 버튼으로 원문을 봐도 곧바로 번역문으로 되돌아가던 문제 수정**: 자동 번역의 트리거인 `CHARACTER_MESSAGE_RENDERED`는 새 응답에만 오는 게 아니라 챗을 열 때·"이전 메시지 더 보기"로 스크롤할 때도 메시지마다 다시 발생합니다. 그런데 원문 보기 선택이 화면에만 남아 있어, 리렌더 한 번에 자동 번역이 도로 덮어썼습니다 — 이제 선택을 메시지에 기록해 두고, 이미 번역이 붙어 있는 메시지는 자동 번역이 다시 건드리지 않습니다
- **메시지 편집 판정 개선**: "다음 이벤트 한 번만 무시" 플래그가 엉뚱한 데서 소모되어, 나중에 진짜 메시지를 편집했을 때 재번역이 조용히 건너뛰어지던 문제 수정 — 이제 원문 해시를 비교해 본문이 실제로 바뀌었을 때만 재번역합니다
- **용어집·말투 카드 격리 강화**: 번역 한 건은 LLM 호출 사이에 대기가 있어, 그 틈에 챗방을 옮기면 뒷문단이 다른 방 용어집으로 번역됐습니다. 이제 번역을 시작한 챗방을 들고 다니며 호출 직전마다 대조하고, 조금이라도 어긋나면 목록을 싣지 않습니다 (fail-closed)
- **구버전 잔재 청소 범위 확대**: 구버전 도장(`bookSeeded`)이 찍히지 않은 챗방도 전역 목록과 대조해 청소합니다 (걷어낸 항목은 격리되며 [가져오기]로 복구 가능)
- **`/interp-book` 명령 추가**: 지금 이 챗방에 실제로 실리는 용어·말투와 격리 상태를 그대로 보여줍니다. "전역으로 새는 것 같다"는 의심이 들 때 확인용

### v1.2.1
- **용어집·말투 카드가 여전히 전역으로 새던 문제 수정**: v1.1.0의 "챗방별 분리"가 챗방을 처음 열 때 구버전 전역 목록을 그 챗방으로 자동 복사했는데, 전역 목록은 비워지지 않아 **모든 챗방이 계속 같은 목록을 물려받고** 있었습니다 — 이제 어떤 경우에도 자동 복사하지 않습니다
- **딸려온 목록 격리**: 새 챗 만들기·분기 과정에서 직전 챗방의 메타데이터가 따라오는 경우를 대비해, 저장소에 챗방 도장을 찍어 두고 다른 챗방 것이면 목록을 비웁니다. 걷어낸 항목은 버리지 않고 격리해 두며, **용어·말투** 탭 상단 안내의 [가져오기]로 이 챗방에 합칠 수 있습니다
- **기존 오염분 자동 청소**: 업데이트 후 챗을 열면, 구버전이 전역에서 퍼 온 항목만 골라내 격리합니다 (직접 쓴 항목은 그대로 두며, 잘못 걷어냈으면 [가져오기]로 복구)
- **편집 즉시 저장**: 용어·말투 편집이 1초 디바운스 저장에만 의존해, 편집 직후 챗방을 옮기면 그 챗방 편집분이 통째로 날아가던 문제 수정
- **비우기 버튼**: 용어집·말투 카드를 이 챗방에서 한 번에 비울 수 있습니다 (다른 챗방 영향 없음)

### v1.2.0
- **설정 수정 시 번역 기억 초기화 버그 수정**: 톤·독자 지시문·프롬프트·용어집·말투 카드·번역 제외 같은 설정을 하나만 고쳐도 캐시 키의 설정 지문이 바뀌어 챗 전체의 번역 기억이 통째로 무효화(사실상 초기화)되던 문제 — 이제 설정은 캐시 키에서 빠지고, 번역 기억은 설정을 아무리 고쳐도 유지됩니다
- **바뀐 설정의 반영 시점**: 새로 번역되는 메시지부터 적용되며, 이미 번역된 메시지에 새 설정(새 용어집·새 톤)을 입히고 싶으면 그 메시지의 🔄 재번역을 누르면 됩니다 (캐시를 무시하고 새로 번역한 뒤 덮어씀)
- **기존 캐시 자동 이전**: 업데이트 후 챗을 열면 기존 번역 기억을 새 키 체계로 한 번에 옮깁니다 — 다시 번역할 필요 없음

### v1.1.0
- **용어집·말투 카드 챗방별 분리**: 전역(모든 채팅 공유) 저장이던 용어집과 말투 카드를 챗방별 저장으로 전환 — 이야기마다 등장인물·고유명사가 달라 서로 섞이던 문제 해결. 기존에 전역으로 쌓아 둔 항목은 각 챗방을 처음 열 때 한 번 자동으로 복사되며, 이후에는 완전히 독립이라 한쪽을 고쳐도 다른 챗방에 영향이 없습니다. 챗을 전환하면 설정 화면 목록도 그 챗방의 것으로 갱신됩니다
