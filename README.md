# Interpres — 이야기 통역사

롤플레잉에 특화된 SillyTavern용 LLM 번역 확장입니다. **v1.0.0**

기계번역(구글·DeepL)의 어색한 문어체 대신, LLM이 캐릭터의 말투와 장면의 온도까지 살려 번역합니다.
원문은 그대로 모델에게 전달되고 화면에만 번역이 표시되므로, 번역이 스토리 품질에 영향을 주지 않습니다.

## 주요 기능

| 기능 | 설명 |
|---|---|
| 응답 자동 번역 | AI 응답이 끝나면 화면에만 번역 표시 (원문은 모델 컨텍스트에 유지) |
| 입력 자동 번역 | 한국어로 쓰면 모델에겐 영어로 전달, 화면엔 내 원문 유지 |
| 말투 카드 | 캐릭터별 존댓말/반말·어미·말버릇을 기록해 번역 문체를 고정. LLM 자동 스캔 지원 |
| 용어집 | 이름·지명·기술명 표기 고정. 캐릭터 카드에서 자동 수집 |
| 번역 결 다이얼 | 직역 위주 ↔ 과감한 의역, 5단계 |
| 번역 기억(캐시) | 문단 단위로 번역을 기억 — 메시지 수정 시 바뀐 문단만 재번역해 비용 절감 |
| 봉인(형식 보호) | 코드·{{매크로}}·이미지·URL·지정 HTML 태그를 `<seal-N/>` 마커로 보호하고 번역 후 복원. 유실 시 자동 재시도 |
| 문맥 연속성 | 직전 원문·번역 쌍을 참고로 첨부해 호칭·대명사·어조 유지 |
| 대조·편집 | 메시지별 원문·번역 나란히 보기 + 번역 직접 수정 |
| 독자 지시문 | "대사는 반말로, 나레이션은 문어체로" 같은 상시 요구사항 |
| 프롬프트 편집 | 고급 탭에서 번역 시스템 프롬프트를 직접 수정. `{{source_lang}}` `{{target_lang}}` `{{pair_notes}}` 매크로는 방향에 따라 자동 치환 |
| 비차단 | 번역은 메인 생성 파이프라인을 점유하지 않아 번역 중에도 채팅 가능 |
| 모델 연결 3종 | 현재 API / 커넥션 프로필 / 커스텀 OpenAI 호환 API 직접 입력 |

## 설치

`SillyTavern/data/<user>/extensions/` 또는 `public/scripts/extensions/third-party/` 아래에
이 폴더를 통째로 복사한 뒤 SillyTavern을 새로고침하세요.

## 사용법

1. 확장 설정 → **Interpres — 이야기 통역사** 드로어를 엽니다.
2. **기본** 탭에서 감상어(화면 언어)와 모델어를 고르고 자동 번역을 켭니다.
3. **모델** 탭에서 번역에 쓸 모델을 연결합니다. 저렴한 소형 모델을 커스텀 API로 붙이는 걸 추천합니다.
4. (선택) **용어·말투** 탭에서 "자동 수집"과 "말투 스캔"을 눌러 카드 기반 프로필을 만듭니다.

### 메시지 버튼

- 🌏 : 이 메시지 번역 / 원문으로 되돌리기 (토글)
- 🔄 : 재번역 — 캐시를 무시하고 처음부터 다시 번역
- ⚖️ : 원문·번역 대조 및 번역 직접 수정

### 슬래시 명령

- `/interp on|off` — 확장 켜기/끄기
- `/interp-msg 12` — 특정 메시지 번역 (번호 생략 시 마지막 AI 응답)
- `/interp-chat` — 아직 번역 안 된 응답 일괄 번역

## 설정 항목

| 항목 | 기본값 | 설명 |
|---|---|---|
| 감상어 / 모델어 | ko / en | 표시 언어와 모델 언어 |
| 번역 결 | 균형(3) | 1 직역 위주 ~ 5 과감한 의역 |
| 문맥 쌍 수 | 2 | 직전 원문·번역 쌍 첨부 개수 (0–6) |
| 번역 기억 | 켬 | 문단 단위 캐시 |
| {{매크로}} 봉인 | 켬 | 매크로 구문 보호 |
| 형식 검증 재시도 | 켬 | 봉인 유실 시 1회 재시도 |
| 번역 제외 태그 | (없음) | 상태창 등 통째로 보호할 태그명 |
| 응답 토큰 한도 | 8192 | 번역 호출 max_tokens |

## 변경 이력

### v1.1.0
- **용어집·말투 카드 챗방별 분리**: 전역(모든 채팅 공유) 저장이던 용어집과 말투 카드를 챗방별 저장으로 전환 — 이야기마다 등장인물·고유명사가 달라 서로 섞이던 문제 해결. 기존에 전역으로 쌓아 둔 항목은 각 챗방을 처음 열 때 한 번 자동으로 복사되며, 이후에는 완전히 독립이라 한쪽을 고쳐도 다른 챗방에 영향이 없습니다. 챗을 전환하면 설정 화면 목록도 그 챗방의 것으로 갱신됩니다

### v1.0.1
- 메시지에 재번역 버튼 추가 (캐시 무시하고 새로 번역)
- 연결 테스트 토큰 예산 상향 (추론 모델이 생각 토큰만 쓰다 잘리는 문제)
- 결과 검증 추가: 언어·문단 구조·길이를 검사해 추론(thinking) 모델이 사고 과정이나 해설을
  번역으로 뱉어낸 출력을 걸러내고, 1회 재시도 후에도 실패하면 원문을 유지
- 사고 블록 제거 강화 (`<thought>` 등 변형 태그, 닫는 태그만 남은 잘린 응답)
- 커스텀 API에서 추론만 하다 잘린 응답(finish_reason=length)을 명확한 오류로 안내
- 프롬프트에 사고 유출 금지 조항 추가 (rev 2)
- UI 버튼 한글 세로 깨짐 수정, 번역 프롬프트 직접 편집 기능

### v1.0.0
- 최초 릴리즈: 응답/입력 자동 번역, 말투 카드, 용어집, 번역 결 다이얼,
  문단 단위 번역 기억, 봉인 형식 보호 + 자동 재시도, 대조·편집 팝업,
  독자 지시문, 문맥 연속성, 일괄 번역, 슬래시 명령, 커스텀 API 지원
